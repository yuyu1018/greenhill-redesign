# グリーンヒルホテルグループ — トップページのデザイン案

公開URL: https://yuyu1018.github.io/greenhill-redesign/

`index.html` をブラウザで開くと確認できます。ビルドやインストールは不要です。VS Code の Live Server でも表示できます。

## デザイン

- 全幅の室内写真と透過ヘッダー。最初は左下に「旅の途中に、日常のつづきに。」を表示します。背景写真は紹介文の範囲まで画面に留まり、スクロールすると見出し・英字・左下のSCROLLが一緒に消え、本文とその下のリンクが画面下から流れてきます。本文とリンクは、PC・スマートフォンとも最初の見出しと同じ左端に揃えています。右下の写真名と切り替えボタンは写真と一緒に画面へ留まり、紹介文を読んでいる間も操作できます。
- 動きを抑える設定ではフェードを無効にします。JavaScriptが無効な場合も、通常のスクロールで紹介文を読めます。
- ページの順序は「FV → 最新2件のお知らせ → ホテル一覧 → 団体・長期滞在などの案内 → 予約案内」。お知らせはコンパクトな帯にまとめています。
- メインナビは「ホテル一覧／グリーンヒルについて／団体・長期滞在／お知らせ／お問い合わせ」。グリーンヒルについてのページ内リンクは、FV内を流れる紹介文へ移動します。宿泊予約は独立したボタンです。
- コンテンツは最大1200pxで、お知らせ・ホテル一覧・滞在紹介の左右端を共通にしています。左右余白は画面幅に応じて連続的に変わり、390pxで約22px、768pxで約66px、1440pxで144px（内側1152px）。最小余白は18pxで、広い画面では最大コンテンツ幅に合わせて中央配置します。見出し列は170〜200px、列間は24〜48pxの範囲で可変です。セクション上下、ホテル間、本文・ボタン周り、フッター、モーダル内の余白も `clamp()` と共通の `--space-*` 変数で管理しています。FVの写真と滞在紹介の背景は全幅です。
- PCでは左に追従するホテル一覧の見出し、右に4施設の紹介を配置。各ホテルの写真は室内写真2枚、その下は「左：ホテル名・特徴・住所・Googleマップ」「右：紹介文・ホテルを見る／予約する」の構成です。Googleマップは施設名と住所を指定した検索リンクで、新しいタブに開きます。スマートフォンでは写真をスワイプでき、「ホテル名・特徴 → 紹介文 → 住所・マップ → ボタン」の順に並びます。
- ホテルの特徴は枠を付けず、細い縦線で区切ります。「ホテルを見る」は緑の枠線と文字・クリーム色の背景、「予約する」は緑の背景・白い文字とSVG矢印です。ボタンの高さは44px。
- 「旅も、仕事も。あなたらしい滞在を。」は左の見出しと説明が画面に留まり、右の一棟貸しのリビング・カフェの写真が縦に流れる構成です。次の写真の上端が画面上から65%の位置に来たら、サービス名・本文・リンクが約0.3秒で切り替わり、上に戻ると前の説明に戻ります。団体・長期予約とカフェの2項目を紹介し、運営代行はフッターから案内します。
- 滞在紹介の背景は細かな粒子感のあるセージグリーンで、画面の左右端まで広がります。見出し・本文・リンク・矢印は白。背景素材は375px角で繰り返し、文字が読みやすい緑色を重ねています。文字・写真は内側の共通コンテナに配置。素材は `assets/textures/sage-grain.png` に保存し、生成方法とプロンプトは同じフォルダのREADMEに記載しています。
- 850px以下、または画面の高さが700px未満では、写真と対応する説明を縦に並べます。JavaScriptなしでも各説明・リンクを表示し、動きを抑える設定では説明の切り替えアニメーションを無効にします。
- 最後の予約案内はクリーム色の背景に、英字・「次の滞在は、グリーンヒルで。」・短い説明・予約ボタンを中央の縦並びで配置。上下の余白は64〜112pxの範囲で可変です。予約ボタンは差し色・高さ44pxを維持し、クリックすると4施設の予約先を選ぶダイアログが開きます。フッターとの境界は共通のコンテンツ幅に揃えた1pxの線で区切っています。
- フッターは背景色を付けず、サイト共通のクリーム色をそのまま使用。文字サイズは住所・ホテル名・案内・コピーライトまで14pxに統一しています。内側は共通の最大1200px。左に緑のロゴと代表住所、Google Mapへのリンク、右の上段に4施設の室内写真と日本語名を並べ、各ホテルの公式サイトへリンクしています。その下に利用案内と企業情報をまとめています。タブレットではロゴと住所が上に移動し、850px以下ではホテルの写真が2列×2段になります。下段はコピーライトと「ページ上部へ＋SVG矢印」。共通のプライバシーポリシーは未作成とのご回答に合わせ、今回はリンクを設けていません。
- 背景は `#f6f3eb`、セージは `#85958c`、差し色は `#a65f46`。日本語はShippori Mincho、英字・数字はCormorant Garamondで、フォントはローカル配信します。
- 本文はPC・タブレットで16px、600px以下では15px、行間は共通で1.8です。`style.css` 冒頭の変数で本文・共通幅・見出し列・可変余白・ボタン寸法・アニメーションを管理し、セクションごとの違いは各パーツの指定にまとめています。
- 写真の手動切り替え、4施設の予約先を選ぶダイアログ、スマートフォン用メニューに対応。矢印・閉じるアイコンの単体SVGは `assets/icons/` にあります。

## ファイル

- `index.html`: 確認用トップページ
- `style.css`: PC・タブレット・スマートフォンのレイアウト。冒頭のCSS変数で色を変更できます。
- `script.js`: FVのスクロール表示、写真切り替え、スクロール時ヘッダー、滞在紹介の説明切り替え、予約・メニューダイアログ
- `assets/`: 既存の `hp/images` から複製した実際のホテル画像。以前の表示用ファイルと、再選定した原寸の写真があります。`assets/selected/` はFigma用の採用原画像11枚です。
- `assets/fonts/`: しっぽり明朝・Cormorant GaramondのWebフォント、CSS、ライセンス。現在のHTMLに含まれる文字のサブセットです。Figmaでは同名のフォントを選んで使用できます。
- `assets/textures/`: 滞在紹介の全幅背景用の粒子テクスチャと、以前の和紙素材。PNGなのでFigmaにも取り込めます。
- `preview-desktop.jpg` / `preview-hero-revealed.jpg`: PCの最初のFVと背景写真の上に本文・リンクが見える位置
- `preview-hero-text.jpg`: 本文が画面下から入ってくる途中のFV
- `preview-news-desktop.jpg` / `preview-hotels.jpg`: PCのお知らせとホテル紹介
- `preview-mobile.jpg` / `preview-hero-mobile-revealed.jpg`: スマートフォンの最初のFVと紹介文を読んでいる位置
- `preview-news-mobile.jpg`: スマートフォンのお知らせ
- `preview-stay-group.jpg` / `preview-stay-cafe.jpg` / `preview-stay-mobile.jpg`: 滞在紹介のPCでの2つの説明とスマートフォンの縦並び
- `preview-contact-desktop.jpg` / `preview-contact-mobile.jpg`: ページ末尾の予約案内とフッター
- `preview-footer-desktop.jpg` / `preview-footer-mobile.jpg`: フッターのPC・スマートフォン表示

## 確認

Chromeで1440px・1024px・768px・390px・320pxを確認。最初の見出し、背景が留まる区間での本文の移動、紹介リンクの表示位置、本文表示中も残る右下の写真名・切り替えボタンの位置と実際のクリック操作、本文と見出しの左端の一致、写真切り替えとキャプション、ヘッダーの切り替え、お知らせの位置とサイズ、ページ内リンク、予約ダイアログ、Escapeでの閉じ操作、スマートフォンのメニューを検証しました。動きを抑える設定とJavaScriptなしの場合も、通常のスクロールで紹介文が読めることを確認しています。

## アニメーション

トップページを開くと、クリーム色の全面背景に緑のロゴがフェードインし、背景が上へ抜けてFVへつながります。通常は約1.5秒で終了し、最初の写真が遅い場合も待機は最大1.2秒、メインスクリプトが読み込めない場合も3.5秒で背景を解除します。スクロール・タップ・キー操作ですぐにスキップでき、ページ内リンクへの直接アクセス、履歴からの復帰、動きを減らす設定では省略します。JavaScriptなしでは最初からページを表示。FVの見出し演出は背景が抜け始めるタイミングに合わせ、写真の自動切り替えはオープニング終了後に開始します。

全体は控えめなフェードを基本にしています。FVは背景写真・英字・日本語見出しが順に現れ、写真を切り替えるとキャプションと番号も短くフェードします。既存のFV内スクロールと滞在紹介の本文切り替えは維持しています。

FVの写真は6秒ごとに、0.8秒のフェードで4施設を循環します。番号は3つ表示のまま、隣のSVGボタンで一時停止・再開できます。番号を手動で選ぶと次の切り替えまで6秒を取り直します。番号の上にマウスを置いたり、キーボードで番号にフォーカスしたりしている間は自動切り替えを止めます。FVが画面から外れた場合、別タブに移った場合、予約・メニューダイアログを開いた場合も停止し、戻ると新しい6秒の間隔で再開します。「動きを減らす」設定では自動切り替えを行わず、番号による手動操作を使用できます。自動で変わる写真名は読み上げを割り込ませず、手動で選んだときだけ通知します。

お知らせは記事を70msずつずらして表示。ホテル一覧は遅延読み込みした写真のデコード完了を待ち、写真を下から上に見せながら1.025倍から元のサイズへ戻します。2枚の写真には100msの時間差を付け、ホテル名・説明・ボタンはまとまりで現れます。滞在紹介の写真は位置を動かさずフェードし、本文切り替えの基準位置を維持。予約案内は英字・見出し・本文・ボタン、フッターはロゴ・住所と各ホテルの写真が現れます。

出現演出は初めて画面に入ったときの1回だけ。文字の移動はPCで10px・スマートフォンで8px、時間はPCで0.6秒・スマートフォンで0.5秒です。ホテル写真はPCで0.85秒・スマートフォンで0.65秒。ボタンの矢印やフッターのリンクの矢印は、マウスを重ねたときに約0.2秒で小さく動きます。

JavaScriptまたはIntersectionObserverが使えない場合は、内容を最初から表示します。「動きを減らす」設定では出現演出を行わず、設定を途中で切り替えた場合も全内容を表示して実行中の演出を停止します。キーボードでまだ表示されていないリンクにフォーカスした場合は、その内容をすぐ表示します。外部のアニメーションライブラリは使用していません。

ChromeでPC（1440px）・スマートフォン（390px）、動きを減らす設定で320pxを確認しました。写真2枚の時間差、一度表示した要素が再び動かないこと、見出しの追従位置、滞在紹介の65%位置での往復切り替え、スマートフォンでの写真スワイプ、予約ダイアログとフォーカス復帰、途中で動きを減らす設定へ変更した場合、JavaScriptなしでの内容表示を検証しています。

## 写真の再選定

収集済みの85種とテーマ内の追加候補を比較し、FV・各ホテル・滞在紹介の写真を再選定しました。FVは美浜のツイン、ガーデンズ美浜の日差しの入る和室、御坊駅前のシングル、アネックスのツインの4枚です。番号は選択中の写真から次の2枚までの3つを表示し、「01・02・03 → 02・03・04 → 03・04・01 → 04・01・02」と循環します。ホテル一覧は御坊駅前の和室とアネックスのシングルを追加。団体・長期滞在は一棟貸しのリビング、カフェは席が残る構図へ変更しています。フッター・予約画面はホテル一覧の代表写真と統一しています。

[採用写真・全候補一覧](画像選定/候補一覧.html)、[選定理由](画像選定/選定メモ.md)、[使用箇所と元画像のCSV](画像選定/使用画像リスト.csv)、[Figma用原画像](assets/selected/) を参照してください。PCとスマートフォンの表示確認画像も `画像選定/` に保存しています。

## 内容とリンク

施設の特徴・各予約先は現行公式サイトを参照。紹介文はデザイン用に新しく作成しました。お知らせは2026年10月13日に公式のお知らせ一覧で確認した最新2件を固定表示し、各記事へ直接リンクしています。WordPressでのお知らせ自動取得は本実装で設定してください。

滞在紹介は1440px・1024pxで左の固定位置と往復スクロールでの説明・リンクの切り替え、768px・390px・320pxと高さ650pxの画面で写真と説明の縦並びを確認。非表示の説明のリンクはフォーカス対象から除外し、キーボードでリンクにフォーカスしている間はその説明を維持します。

共通幅の調整後は1920px・1440px・1366px・1351px・1280px・1100px・1024px・851px・768px・600px・390px・320pxで確認。お知らせ・ホテル一覧・滞在紹介の左右端の一致、最大1200px、全幅背景、ヘッダーとホテルのボタンの収まり、本文のサイズと行間、滞在紹介の切り替えタイミングを確認しています。

ページ末尾の予約案内は1440px・1024px・768px・390px・320pxで中央配置、余白、本文16pxと現在の行間、ボタンの高さ44pxと横幅を確認。PCとスマートフォンでボタンの実クリックから4施設の選択が開き、Escapeで閉じて元のボタンへフォーカスが戻ることも確認しています。

写真付きのフッターは1920pxから320pxまでの配置を確認。背景色なし・14pxの文字・住所の追加後も、1440px・1024px・768px・390px・320pxで文字と写真の収まり、Google Mapのリンク先と新しいタブの設定を確認。「ページ上部へ」の実クリックでFVへ戻ることも確認しています。
