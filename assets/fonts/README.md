# デザイン用の明朝・セリフ体

- 日本語：Shippori Mincho（しっぽり明朝）400 / 500
- 英字・数字：Cormorant Garamond 400 / 500 / 600

数字には高さの揃ったライニング数字を使用しています。写真番号・日付・住所・予約メニューの番号には等幅数字も指定し、桁の幅を揃えています（CSSの `font-variant-numeric: lining-nums tabular-nums`）。

Google Fonts公式APIから、現在のHTMLに含まれる文字と数字0〜9を収録したWebフォントを取得しています。日本語・英字ともローカル配信で表示できます。新たな文字を追加した場合、収録されていない文字はOSの明朝体で表示されます。

FigmaではGoogle Fontsの同名フォントを選択してください。Web用のファイルをOSにインストールする必要はありません。

- https://fonts.google.com/specimen/Shippori+Mincho
- https://fonts.google.com/specimen/Cormorant+Garamond
