# 採用した写真の原画像（Figma用）

今回の再選定で採用した11枚です。既存の写真をそのまま複製しています。画像の縮小・拡大・色調整は行っていません。

Figmaには、このフォルダのJPGを取り込んでください。各使用箇所に合わせてフレーム内でトリミングできます。

`原画像リスト.csv` にコピー元、原寸、SHA256を記録しています。HTMLで以前から使用している美浜のツイン・御坊駅前のシングル・アネックスのツイン・美浜の和室は、既存の表示用ファイルを継続しています。

使用箇所と選定理由は [使用画像リスト.csv](../../画像選定/使用画像リスト.csv) と [選定メモ](../../画像選定/選定メモ.md) を参照してください。写真の所属する施設を入れ替えずに使用しています。
